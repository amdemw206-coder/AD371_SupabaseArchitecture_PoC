PostgreSQL as the Single Source of Truth

Supabase rejects proprietary vendor lock-in by wrapping time-tested open-source tools around a powerful PostgreSQL relational database. Instead of proprietary abstraction layers, Supabase treats PostgreSQL as both data store and application engine.

Composable Open-Source Stack

Each subsystem is a standalone open-source project connected seamlessly through Kong API gateway and native Postgres database roles.

Zero proprietary black boxes

Database-First Security (RLS)

Authorization logic is delegated straight to Postgres Row Level Security (RLS) policies. JWT claims are injected directly into session variables.

Granular row protection

Extensibility via Extensions

Leveraging powerful Postgres extensions like `pgvector` for AI embeddings, `pg_cron` for background jobs, and `PostGIS` for geospatial mapping.

Unmatched database extensibility

Core Components Breakdown Matrix

Detailed breakdown of the open-source microservices powering the Supabase ecosystem.

Auth & Security Go

GoTrue (Auth)

A JSON Web Token (JWT) based API server that manages users, issues JWT tokens, handles OAuth providers, and multi-factor authentication (MFA).

Underlying Tech: GoTrue (Go)
Database Role: auth schema tables
API Layer Haskell

PostgREST

Turns any PostgreSQL database directly into a zero-boilerplate RESTful API. Automatically inspects database schemas and RLS policies.

Underlying Tech: PostgREST (Haskell)
Database Role: Direct SQL-to-JSON mapping
Realtime Elixir

Realtime (Phoenix)

Allows developers to listen to PostgreSQL changes via WebSockets using Postgres logical replication features.

Underlying Tech: Phoenix / Elixir
Database Role: Postgres Logical Replication (WAL)
Data & Storage Node.js

Storage API

Manages large files such as images, videos, and documents using standard S3-compatible storage backend with Postgres metadata.

Underlying Tech: Fastify / Node.js + S3
Database Role: `storage.objects` table + RLS
Compute TypeScript

Edge Functions

Serverless TypeScript functions distributed globally on Deno Deploy for custom business logic and webhooks.

Underlying Tech: Deno / V8 Engine
Database Role: Triggered via HTTP
Database Core C / Postgres

Postgres & pgvector

The heart of Supabase. Packed with extensions like `pgvector` for vector embeddings & AI semantic search.

Underlying Tech: PostgreSQL 15 + Extensions
Database Role: Single Source of Truth
